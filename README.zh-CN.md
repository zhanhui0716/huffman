# C++ 哈夫曼编码

[English](README.md)

这是一个 C++ 控制台程序。它根据预设的英文字母频率构建哈夫曼树，打印 `A` 到 `Z` 的编码表，并将用户输入的一行大写英文字母转换成哈夫曼编码。

## 编译与运行

在本仓库目录打开终端，使用 GCC 的 `g++`（Windows 下可用 MinGW），选择 C++11 或更新的标准。源码使用了 `<bits/stdc++.h>`。

**Windows（PowerShell）**

```powershell
g++ -std=c++11 "哈夫曼树.cpp" -o huffman.exe
.\huffman.exe
```

**Linux**

```bash
g++ -std=c++11 "哈夫曼树.cpp" -o huffman
./huffman
```

## 运行示例

程序先打印根节点权值 `10002` 和 26 个字母的编码，再提示输入。输入 `ET` 并回车：

```text
请输入一串大写英文字母：ET
哈夫曼编码：100000
```

程序把 `E` 的编码 `100` 和 `T` 的编码 `000` 拼在一起。输入至少包含一个 `A` 到 `Z` 的大写字母。空输入、小写字母、空格和标点都会被拒绝。

## 实现原理

1. 用数组存储哈夫曼树，先把 26 个字母作为叶子节点。每次选出两个尚无父节点且权值最小的节点进行合并，最终得到 51 个节点。
2. 生成每个字母的编码时，从叶子沿父节点回到根节点，记录左分支为 `0`、右分支为 `1`，再反转记录的位串，得到从根到叶子的编码。
3. 编码输入时，用 `ch - 'A'` 得到每个字母在编码表中的下标，再依次拼接对应的编码。

源码也实现了 `decode()`。它从根节点出发，走到叶子时输出字母，遇到非 `0`、`1` 的字符或末尾编码不完整时返回 `false`。当前 `main()` 的交互入口提供字符串编码功能。
